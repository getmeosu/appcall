# Everhour

International Everhour REST API recipe (v0.2.0). Authenticate with `X-Api-Key` against `https://api.everhour.com`.

Healthcheck is documented `GET /users/me`. Coverage includes users, projects, clients, tasks, time records, timers, sections, and invoices, plus EventOnly webhooks for project, task, timer, and client events.

The native key is `everhour`.
