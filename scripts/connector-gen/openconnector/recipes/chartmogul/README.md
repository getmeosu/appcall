# ChartMogul

Read-only curated recipe for the international ChartMogul API. Configure the API key as the Basic-auth username; the password is intentionally blank. Operations are `healthcheck`, `account.get` (optional comma-separated `include`), `sources.list`, and `customers.list`.

Upstream docs: https://dev.chartmogul.com/reference/retrieve-account/, https://dev.chartmogul.com/reference/sources/list/, and https://dev.chartmogul.com/reference/customers/list/. Company identity: https://chartmogul.com/imprint/. Live smoke remains unverified.
