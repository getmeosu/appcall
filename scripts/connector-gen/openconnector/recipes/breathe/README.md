# Breathe

International Breathe HR API recipe. Configure an API key from Breathe API setup; requests use `X-API-KEY` against `https://api.breathehr.com/v1`. Covers credential health, employees, locations, departments, working patterns, holiday allowances, leave requests, absences, and sicknesses. Pagination is caller controlled and provider `Link` headers are never followed. Live authentication is unverified. Source: oomol-lab/open-connector at `33dd4ad6ee22f9ce5158a1516a11d8b8566b5c8a`.
