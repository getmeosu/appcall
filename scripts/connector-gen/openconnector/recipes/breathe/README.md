# Breathe

Read-only international Breathe HR API recipe. Configure an API key from Breathe API setup; requests use `X-API-KEY` against `https://api.breathehr.com/v1`. Covers credential health, employee listing, and location listing. Pagination is caller controlled and provider `Link` headers are never followed. Live authentication is unverified.
