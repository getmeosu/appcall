# Postmark

Read-only Postmark Server API recipe. Configure a server token. List operations require count and offset; outbound search must keep count + offset within Postmark's documented 10,000 result window. Operations use the official international API; no send or template mutation operation is exposed. Source attribution: oomol-lab/open-connector at `33dd4ad6ee22f9ce5158a1516a11d8b8566b5c8a`. Live smoke is unverified.
