Postmark Server API recipe. Configure a server token from Server > API Tokens. Coverage is the origin healthcheck plus the 46 Composio POSTMARK HTTP tools: messages, bounces, templates, batch templated send, message streams, suppressions, webhooks, inbound rules, stats, and the public SpamCheck API on spamcheck.postmarkapp.com. List endpoints that document count/offset keep those fields required and caller-controlled (count + offset must stay within Postmark's 10,000-result window). Suppressions use official {EmailAddress} objects. GET_BROWSER_USAGE.ServerID is accepted and unused because the server token already scopes the server.
