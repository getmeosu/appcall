# New Relic recipe

US New Relic on `api.newrelic.com` with the documented `Api-Key` user key. REST API v2 covers APM applications (hosts, instances, metrics, deployments), mobile applications, key transactions, browser apps, alert policies and conditions (APM, NRQL, synthetics, external service, entity, location failure), channels, incidents, violations, events, original-model users, servers, and labels. NerdGraph `POST /graphql` covers NRQL, entities, tags, dashboards, workloads, golden signals, GraphQL alert policies and NRQL conditions, AI notifications and workflows, synthetics monitors, API keys, user management, browser and mobile agent settings, log partitions, lookup tables, service levels, cloud links, accounts, and change-tracking deployment markers. Synthetic monitor REST uses `synthetics.newrelic.com`. Infrastructure alert conditions use `infra-api.newrelic.com`. Insights event ingest and trace ingest are not included: those hosts require a license key, and this connector's shared auth header is the user key. Live authentication is unverified. Some NerdGraph input type names follow the public tutorials and are not live-schema verified.
