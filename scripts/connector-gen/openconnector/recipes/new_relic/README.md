# New Relic recipe

REST API v2 on `api.newrelic.com` with the documented `Api-Key` header: APM applications (hosts, instances, metrics, deployments), mobile applications, key transactions, browser apps, alert policies and conditions (APM, NRQL, synthetics, external service, entity, location failure), channels, incidents, violations, events, original-model users, servers, and labels. NRQL uses NerdGraph `POST /graphql`. Live authentication is unverified.
