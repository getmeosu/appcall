# Breezy HR

International Breezy HR API recipe. The API token is sent in the `Authorization` header exactly as supplied, without a Bearer prefix. Version 0.2.0 adds company, department, position, candidate, pipeline, and team HTTP operations plus EventOnly webhooks for candidate added, candidate status updated, and position added. Live authentication is unverified. Source attribution: oomol-lab/open-connector at `33dd4ad6ee22f9ce5158a1516a11d8b8566b5c8a`.
