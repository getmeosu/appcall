# PostGrid

PostGrid Print & Mail API v1 recipe covering the Composio `POSTGRID` toolkit (60 tools) plus `healthcheck`. Configure a test or live Print & Mail API key from the PostGrid dashboard settings. The runner sends `x-api-key` plus `Accept: application/json` to `https://api.postgrid.com/print-mail/v1`. This recipe is not the Address Verification API (`/v1/addver`).

Selected operations are the origin/main contact and template reads, `healthcheck` (`GET /templates?limit=1`), and the remaining Composio tools as real HTTP actions: contacts/templates/letters/postcards/cheques/boxes/bank accounts/return envelopes/trackers/webhooks/events/template editor sessions/self-mailers/sub-organizations/postal statements. Letter and cheque create map Composio `fromAddress` onto PostGrid `from`; contact create maps `organization` onto `companyName`. Cancel-with-note uses `POST /{resource}/{id}/cancellation`. Test progressions use `POST /{resource}/{id}/progressions`. Responses keep raw PostGrid JSON under `data`. Path IDs are URL-encoded.
