# Salesflare

Salesflare REST API at `https://api.salesflare.com`. Bearer API keys are created in Settings > API keys.

## Operations

Origin healthcheck plus contacts/accounts/opportunities list contracts are kept. Remaining Composio SALESFLARE tools are first-party declarative request blocks against the official OpenAPI (`https://api.salesflare.com/openapi.json`).

Successful new actions return the parsed provider JSON under AppCall `data`. Origin list actions keep their `{contacts|accounts|opportunities, pagination}` mapping.
