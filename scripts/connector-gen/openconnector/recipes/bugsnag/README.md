# Bugsnag recipe

Read-only Bugsnag Data Access API recipe using a personal auth token in the documented `Authorization: token ...` header. Operations cover healthcheck, organizations, projects under an organization, and project error groups (list + get). Host is `api.bugsnag.com` only; notify/ingest is out of scope. Live authentication remains unverified. Source is Apache-2.0 licensed upstream OpenConnector at the pinned revision.
