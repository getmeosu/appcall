# Folk

International Folk CRM API v1 recipe. Store an API key as `apiKey` and send `Authorization: Bearer <apiKey>` to `https://api.folk.app/v1`.

Version 0.2.0 keeps the original user/group/people/company reads and adds people/company/group/note/task writes plus EventOnly webhooks for person, company, and note events.
