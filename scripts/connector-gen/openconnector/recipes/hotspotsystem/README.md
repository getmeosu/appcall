# HotspotSystem

International **HotspotSystem API v2.0** recipe (v0.2.0). Generate an API key from Control Center > Tools & Settings > API Keys. The runner sends `sn-apikey` to `https://api.hotspotsystem.com/v2.0`.

Covered HTTP operations: operator `healthcheck`/`ping`, locations, location options, customers, subscribers, vouchers, and MAC/voucher/social/paid transactions (global and location-scoped). EventOnly webhooks: customer/subscriber create and transaction create events.

Official docs: https://www.hotspotsystem.com/apidocs/api/reference and https://www.hotspotsystem.com/apidocs/webhooks/. Native category is `productivity`.
