# AddressZen

AddressZen REST API v1 recipe. Store an API key (prefix `ak_`) as `apiKey`. Requests send `api_key` as a query parameter to `https://api.addresszen.com/v1`.

## Operations

Healthcheck, address autocomplete/retrieve/verify, place find/resolve, email and phone validation, key details/usage, and licensee plus config management.
