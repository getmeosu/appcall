# Affinda

International Affinda REST API v3 recipe. Configure an API key from user settings and the API region slug from the Affinda web app host: `api` (AUS/Global), `api.us1` (US), or `api.eu1` (EU). The runner sends `Authorization: Bearer` to `https://<region>.affinda.com`.

Covered operations: origin healthcheck plus organization, workspace, document-type, document, tag, usage, and resthook reads/writes, and the remaining Composio AFFINDA tools mapped onto official `/v3` JSON (and URL-encoded) routes — collections, extractors, annotations, data points, mapping data sources, invitations, indexes, Search & Match, validation results, memberships, API users, and document splitters. `documents.create` uploads by URL as `application/x-www-form-urlencoded` because the declarative runtime cannot emit multipart file blobs.

Caller-supplied `apiBaseUrl` is replaced by required stored `region` interpolating `https://{{region}}.affinda.com` with allowlisted official hosts only. Docs prose says "basic authentication"; OpenAPI and the pinned source use `Authorization: Bearer`. Native category is `utility` (source AI/Data are not in native CATEGORIES). The upstream user-agent is not sent. Responses keep raw Affinda JSON under `data` except 204 deletes, which return `{deleted: true}`. Resthook create/list/get/update/delete cover webhook subscription management; inbound EventOnly document events are not compiled as recipe actions.
