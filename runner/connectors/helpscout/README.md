# Help Scout Mailbox API v2

This connector exposes Help Scout Mailbox API v2 operations for mailboxes, users, tags, conversations, threads, and customers. Reads cover list/get plus the current user. Writes cover conversation create/update, customer create/update, reply threads, and notes. It uses the managed OAuth2 connection flow and the transient `accessToken` supplied by the runner. Help Scout documents the authorization and token endpoints, refresh grant, and rotated tokens; this manifest declares refresh support and no synthetic scopes. The Rust control plane owns stored credentials and OAuth refresh; Bun receives a transient credential lease/token for bounded request execution.

Collection pagination is explicit and page based. The connector sends `pageSize=50` for inboxes, mailboxes, users, tags, customers, and threads, and `pageSize=25` for conversations. Response `_embedded` collections and `page` metadata are returned as data. Provider `_links` are metadata only and are never followed. Create endpoints that return an empty 201 body surface the `Resource-ID` and `Location` headers. Conversation updates send one JSON Patch operation to `PATCH /conversations/{id}`.

Fixtures and tests prove request and mapping behavior only; they are not live-provider qualification.
